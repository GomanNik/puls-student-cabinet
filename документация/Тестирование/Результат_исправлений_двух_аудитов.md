- DashboardView.upcomingDeadlines: добавлена единая CalendarItem-проекция работ/этапов/аттестаций на 14 дней; upcomingWorks сохранён. Исправляет ФТ-04/75, не создаёт новую сущность/таблицу сроков.
- 429 + Retry-After у search/export/read/read-all/download; HEAD также описывает 413/416. Пути и число операций (49) сохранены.
- CSP frame-src blob: только для просмотра уже авторизованного PDF; object-src none и frame-ancestors none сохранены. Внешние сайты в iframe не разрешены.
- Миграции 001/002 не переписывались; новая 003 добавляет audit и source timestamp. Prisma FK/CHECK остаются в SQL; генерация клиента не является проверкой миграции.

## 6. Все 49 HTTP-операций

Общий read-путь: transport → requireSession → query/input → предметная проверка прав → источник → Zod DTO → private/no-store. Общий command-путь дополнен строгим Origin, JSON/body cap и повторной сессией; P-изменения имеют транзакционный session lock. Исключение login — публичная credential-проверка с limiter/Argon2; logout отзывает только token текущего браузера. HEAD явно реализован с той же объектной ACL, без body; бинарные GET используют фиксированный MIME/byte cap и дополнительную проверку перед выдачей. Ни один HTTP-запрос в задаче не выполнялся.

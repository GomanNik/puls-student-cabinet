# План тестовых данных

Наборы здесь описаны логически. Файлов JSON и персональных данных на этапе 0 нет; будущие значения должны быть вымышленными. Это не утверждённая модель полей.

| Набор | Состав и назначение | Проверка |
|---|---|---|
| Два студента | Два независимых аккаунта с разными записями профиля, оценок, заявок, обращений и уведомлений | Изоляция и подмена ID |
| Группа и подгруппы | Общая группа, несколько подгрупп по одной/разным дисциплинам, разные назначения студентов | Отбор занятий по дисциплине и подгруппе |
| Оценивание | Минимум две различимые модели, в том числе балльно-рейтинговая при подтверждении правил | Отображение без смешения шкал |
| Расписание | Обычные занятия, изменение и связанное уведомление, период без занятий | Согласованность и пустое состояние |
| Заявки и обращения | По одной собственной операции на аккаунт, доступная и чужая запись | Сохранение, статус внутри заявки, запрет чужого доступа |
| Внешние ответы | Успех, ошибка и отсутствие данных по каждому утверждённому направлению | Устойчивость сервера и интерфейса |

Конкретные даты, имена, значения, виды заявок и оценок задаются после ответов [ПРД-04](../09_Реестр_нерешённых_вопросов.md) и [ПРД-05](../09_Реестр_нерешённых_вопросов.md). Использовать только вымышленные персональные данные (РЕШ §2.3 п. 7).

# Единый реестр задач

Исходный план составлен 2026-11-10; актуализация статусов зависимостей по независимому аудиту 11.11.2026. Приоритеты задач — плановые, не оценки готового приложения. `P0` — необходимая защита/ядро, `P1` — основной объём, `P2` — сопровождение. `Специфицировано, не закрыто` означает наличие действующих решений и документов, **не** выполненный код или пройденные тесты. Согласованные в 01–08 и обоих OpenAPI технические правила **не требуют повторного утверждения** для начала вертикали; только новые предметные решения требуют отдельного основания.

**Поздний регламент заказчика от 13.11.2026:** сейчас этап А — только реализация крупными блоками. Этап Б с тестами, сборками, браузерными и прочими проверками начинается исключительно по отдельной команде; прежние рекомендации об инкрементальных проверках ниже этим заменены.

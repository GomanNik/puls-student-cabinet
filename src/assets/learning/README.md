# Учебные файлы ПУЛЬС

Собственные вымышленные демонстрационные материалы без реальных персональных данных и логотипа вуза. PDF, DOCX, PPTX и XLSX созданы специализированными библиотеками; файлы не являются переименованным текстом.

| Файл в репозитории | Имя при скачивании | Назначение |
|---|---|---|
| guide.pdf | Методические рекомендации.pdf | Методичка к работе с источниками |
| notes.pdf | Конспект.pdf | Самостоятельный материал без связи с заданием |
| solution.docx | Структура решения.docx | Вторая методичка к той же работе |
| research.pptx | Учебное исследование.pptx | Два учебных слайда |
| observations.xlsx | Наблюдения.xlsx | Вымышленные исходные сведения для сравнения |

Источники генерации: `scripts/create-learning-assets.py` (bundled Python, reportlab/python-docx), `scripts/create-learning-office.mjs` (bundled Node, @oai/artifact-tool). Рабочие зависимости находит `load_workspace_dependencies`; устанавливать их в приложение не требуется. Перед запуском второго генератора задаётся `PULS_ARTIFACT_MODULES` с каталогом bundled Node packages. При повторной генерации служебные `*.inspect.ndjson` не входят в приложение.

Кириллица в PDF использует Noto Sans из `../fonts/` с лицензией OFL. Пути отдачи определяет только server-only allowlist `learning-assets.ts`; файлы не размещены в `public`. На этапе А файлы созданы, но не открывались в офисных приложениях, не рендерились и не проверялись парсерами. Читаемость/просмотр и скачивание через приложение проверяются на этапе Б.

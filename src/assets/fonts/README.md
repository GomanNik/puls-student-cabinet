# Шрифт для PDF-экспорта

Noto Sans Regular, The Noto Project Authors. Лицензия SIL Open Font License 1.1 находится в `OFL.txt` и распространяется вместе со шрифтом.

Источник файла: https://github.com/notofonts/noto-fonts/blob/main/hinted/ttf/NotoSans/NotoSans-Regular.ttf

Шрифт встраивается в PDF на сервере. Во время экспорта внешние шрифты и URL не загружаются. Визуальная проверка экспортированных документов относится к этапу Б.
